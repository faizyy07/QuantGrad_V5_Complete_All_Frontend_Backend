# Reference Layout Notes

## Luxury Trading Consultancy Website

The first additional reference uses a **quiet luxury landing-page hierarchy**. Its strongest transferable ideas are a compact, high-contrast top navigation, a single gold-accent action in the upper-right corner, a contextual pill above the headline, and an oversized two-line proposition that gives the interface an immediate point of view. The hero background combines an atmospheric finance image with a faint price-chart trace, so the content reads clearly without becoming visually flat.

For QuantGrad, retain the hierarchy rather than the gold palette: use the compact navigation and contextual pill, but express them in cobalt-blue glass. The terminal should keep a short, decisive model-state headline and a subtle chart texture behind it.

## SaaS B2B Trading Landing Page

The second reference is most useful for its **information architecture**: it presents the product in a deliberate progression of an intelligent-trading proposition, a compact embedded terminal, popular instruments, account tiers, and small analysis modules. QuantGrad will adapt this with a distinct landing-to-terminal transition: a concise hero with a live model-state call-to-action, followed by a workspace instead of marketing cards.

## Crypto Trading App UI Kit

The kit demonstrates a practical data hierarchy that transfers well to the desktop terminal. The strongest elements are the large portfolio summary card, dual primary/secondary action buttons, instrument rows with icon, value, change, and miniature trend, a focused market-status headline, and bottom-level section navigation. For QuantGrad, the portfolio card becomes a **model summary**, and the coin rows become a **watchlist** with instrument, last price, change, and a compact sparkline. This gives the dashboard dense market information without sacrificing scanability.

## Chosen QuantGrad Layout System

QuantGrad will combine the first reference's atmospheric blue hero and strong proposition, the second reference's landing-to-workspace hierarchy, the crypto kit's scanable watchlist rows and summary/action card, and the original Capi-style blue-glass treatment. The desktop terminal will use a fixed top bar, a left contextual rail with watchlist and model summary, a central price chart and analysis console, and a right decision ledger. Every panel will retain a one-line purpose, a quiet border, readable spacing, and only meaningful blue glow.
