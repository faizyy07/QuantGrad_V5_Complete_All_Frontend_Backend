# Model Analytics Visual Validation

The local-model decision workspace was manually reviewed in the running terminal using a representative structured inference payload. The review focused on legibility, information hierarchy, calculation traceability, and responsive layout rather than any assessment of model quality or investment performance.

| Viewport | Observed outcome |
|---|---|
| Desktop, 1280 × 900 | The central market canvas and right-hand model evidence ledger retain a clear decision-river composition. The decision label, normalized confidence gauge, trend/structure/risk topology, and expanded calculation trace are visible without overlap. Returned factor scores show bounded cobalt bars, while unbounded metrics remain numeric only. |
| Mobile, 390 × 844 | The layout collapses into a readable vertical sequence. The decision score remains prominent, calculation rows preserve labels and values without horizontal overflow, and the calculation-trace control remains accessible. |
| Public-feed pending state | The former generic chart placeholder has been replaced with a chart-derived evidence preview containing a telemetry label, price-trace topology, dotted confidence horizon, and source-state label. |

> The interface presents model-returned data transparently. It does not infer missing factors, manufacture scores, provide investment advice, or initiate any trade execution.
